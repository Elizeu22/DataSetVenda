📊 Processamento de Dataset de Vendas com LINQ
📌 Descrição

Processe um dataset de vendas aplicando operações LINQ encadeadas para extrair
insights relevantes de forma eficiente e escalável.

🚀 Objetivo

Demonstrar o uso avançado de LINQ em C# para manipulação de grandes volumes de
dados (10.000+ registros), aplicando filtros, agregações, ordenação e paginação.

🧠 Funcionalidades
1. 🔍 Filtro de Dados
Filtra registros de vendas com base em:
Período (data inicial e final)
Região


2. 📊 Agrupamento e Métricas
Agrupa os dados por vendedor
Calcula:
💰 Total de vendas
📈 Média de vendas
🔝 Valor máximo de venda


3. 🔄 Ordenação e Paginação
Ordena os resultados por múltiplos critérios, como:
Total de vendas (desc)
Média (desc)
Implementa paginação para melhor performance e visualização:
Página atual
Tamanho da página


🛠️ Tecnologias Utilizadas
C#
.NET
LINQ (Language Integrated Query)
